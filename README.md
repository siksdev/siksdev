## About Me

I'm Renato, a software development student from **Rio Grande do Sul, Brazil**. I'm currently focused on improving my skills in **C#, .NET and web development**, while continuously learning how to design cleaner, more maintainable software.

Alongside my studies, I build and deliver **RedM and FiveM systems through SafeStudio**, which gives me hands-on experience turning ideas into working projects, solving real problems and maintaining systems beyond the initial prototype.

I enjoy learning by building, understanding how things work underneath, and improving each project as I gain more experience.
